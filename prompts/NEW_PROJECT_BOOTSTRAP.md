# 신규 프로젝트 초기화 프롬프트

아래 문장을 Codex, Claude Code 또는 ChatGPT GitHub 작업에 그대로 사용한다.

```text
이 저장소는 alclssna33/ai-project-template에서 생성된 신규 프로젝트다.
애플리케이션 기능 개발은 시작하지 말고 프로젝트 초기화만 진행하라.

1. 최신 기본 브랜치의 AGENTS.md를 첫 저장소 문서로 읽어라.
2. AGENTS.md가 지정한 docs/AI_DEVELOPMENT_POLICY.md를 읽어라.
3. repository_full_name, 기본 브랜치, 최신 기본 브랜치 SHA, 열린 PR·브랜치를 확인하라.
4. 고유 초기화 브랜치와 격리된 worktree 또는 동등한 환경을 사용하라.
5. scripts/initialize-project.ps1의 입력값을 현재 저장소 기준으로 확정하라.
6. AGENTS.md와 docs/PROJECT_GUIDE.md의 확정 가능한 값만 채워라.
7. Setup/Test/Lint/Typecheck/Build/Run은 실제 manifest와 문서 근거가 없으면 미구성으로 유지하라.
8. README.md를 프로젝트 README로 초기화하라.
9. .claude/settings.json, CLAUDE.md, PR 템플릿, 정책 버전의 일관성을 확인하라.
10. scripts/check-policy.ps1 또는 동등한 검사를 실행하라.
11. 초기화 관련 파일만 commit·push하고 Draft PR을 만들어라.
12. 기본 브랜치에 직접 push하거나 merge하지 마라.
```
