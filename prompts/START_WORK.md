# 일반 작업 시작 프롬프트

```text
이 저장소에서 다음 작업을 시작한다: <작업 내용>

1. 최신 기본 브랜치의 AGENTS.md와 공통 정책, 대상 경로의 하위 지침을 먼저 읽어라.
2. 읽기 전용 preflight로 저장소, 브랜치, worktree, clean 상태, 최신 기본 브랜치 SHA,
   upstream ahead/behind, 열린 PR·Issue, 겹치는 파일을 확인하라.
3. 작업 유형과 위험 수준을 분류하라.
4. 쓰기 작업이면 최신 기본 브랜치에서 고유 브랜치와 격리 환경을 만들고 원격 선점 기록을 남겨라.
5. 수정 전 작업 범위, 예정 파일, 검증 계획을 보고하라.
6. 요청을 만족하는 최소 범위만 변경하라.
7. 테스트와 전체 diff를 검토하고 feature branch에만 commit·push하라.
8. Pull Request를 만들되 사용자의 현재 PR 번호 지정 승인 없이는 merge하지 마라.
```
